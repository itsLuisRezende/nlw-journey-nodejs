#  NLW Journey – Back-end Node.js

## 1. Objetivo do projeto
Construir o back-end da aplicação desenvolvida durante a **NLW Journey**, evento da Rocketseat. O foco foi criar uma API robusta e escalável que fornece suporte à aplicação cliente, seguindo boas práticas de arquitetura e estruturação moderna.

## 2. Resultado
Foi desenvolvido um servidor em **Node.js** com **TypeScript**, capaz de processar e responder requisições de forma rápida e segura. A estrutura proporciona endpoints preparados para manipular dados de forma consistente, alinhada à aplicação front-end que lida com planejamento de viagens.

## 3. Ferramentas utilizadas
- **TypeScript** – para tipagem estática e segurança no código  
- **Node.js** – ambiente de execução JavaScript no servidor  
- **API REST** – padrão para comunicação com front-end  
- **Prisma ORM** – modelo de dados, migrações e acesso ao banco  
- **.env / variáveis de ambiente** – para configuração segura e flexível  
- Estrutura de pastas organizada seguindo padrões de escalabilidade  

## 4. O que eu aprendi (habilidades/competências adquiridas)
- Desenvolver uma **API back-end** com **Node.js + TypeScript** e boa organização de código  
- Utilizar o **Prisma** para modelagem de dados e integração com banco de dados  
- Gerenciar configuração sensível com variáveis de ambiente e `.env.example`  
- Estruturar um projeto back-end pensando em escalabilidade e boas práticas de desenvolvimento  

## 5. Existem melhorias a serem feitas?
- Adicionar **autenticação e autorização** (por exemplo, via JWT) para proteger rotas  
- Implementar testes automatizados (unitários / integração) para aumentar confiabilidade  
- Criar documentação interativa da API (por exemplo, com Swagger ou Postman)  
- Implementar **deploy contínuo** com integração em CI/CD (GitHub Actions ou outro)  
- Adotar padrões de arquitetura avançados (como SOLID, DDD ou padrões de repositório/factory)
